## J0 — shared contracts

Freeze global/workspace navigation, multi-reality render plans, compute connection state, durable result state and reality-fidelity acceptance metadata.

## J1 — discoverability

Correct Home truth, restore global discovery access, expose Create clearly, keep Live honest, and make deferred surfaces explicit.

## J2 — creator completion

One Create submission -> one render plan -> selected realities -> real compute -> all requested artifacts -> direct Watch.

## J3 — durability

Neon control-plane persistence, R2 artifacts, cross-instance reads, redeploy persistence and Library/Jobs recovery.

## J4 — role/workspace completion

Minimal Analyst Clips/Notes, Rights Holder edit/revoke/audit, Operator contextual preview, and navigation that does not strand users.

## J5 — reality fidelity

Production-capable perception, meaningful entity/event materialization, no-empty-SWM final path and content-sensitive derived realities.

## J6 — final proof

Clean browser, two materially different real clips, one-submission four-reality creation, restart/redeploy durability, human visual review, public MVP gate.
