## THE metric designs (the acceptance's core — implemented ready-to-run, typed not-measured; self-checked 26/23+3)

The acceptance names "player/avatar motion fidelity and temporal identity stability"; the frozen profile adds style adherence + temporal consistency. Every metric is IMPLEMENTED in `benchmark_wan22animate.py` with its exact definition in the module, and every one is self-checked against hand-computed cases (`results/metric-selfcheck.json` — implementation evidence, NOT a model measurement):

1. **MOTION FIDELITY** — `motion_fidelity_joint_error(ground_truth_track, output_track, reference_scale)`. The GROUND TRUTH is the CANONICAL entity motion/state: the SWM participant entities' positions (`WorldEntity.state` — the kind-specific `pitchPosition` etc. `UncertainValue` records) sampled at the fixture's frame times and projected through W601 `projectScene` into the output video's pixel frame. The OUTPUT track is the pose/joint trajectory ESTIMATED FROM THE RENDERED OUTPUT VIDEO by a fixed pose estimator (the adequate-host design pins the candidate's own `process_checkpoint/pose2d` vitpose estimator, applied IDENTICALLY to the conditioning video and the output — the same estimator for both comparison lanes). Reported: `meanNormalizedJointError` (mean over frames and joints of the pixel error normalized by the frame diagonal — resolution-independent), `endpointJointError` (does the performance END where the canonical state ends), and `velocityDirectionAgreement` (the mean cosine between per-joint frame-to-frame deltas — the DYNAMICS; a constant spatial offset scores position error but perfect direction, the metric split the self-check pins). The CONDITIONING-VIDEO view (output track vs the performance video's own pose track — the video-model convention) is reported SEPARATELY, never conflated with the canonical view.
2. **TEMPORAL IDENTITY STABILITY** — `identity_drift(frame_embeddings, reference_embedding)`. Per frame, an identity descriptor extracted from the detected character/face crop (the embedding model fixed by the fixture contract, applied identically to the authorized avatar reference image → the ANCHOR). The anchor is the AUTHORIZED REFERENCE, not the output's own first frame — identity is defined by what the output is supposed to preserve. Reported: `meanPairwiseIdentityDistance` (mean 1−cos over ALL frame pairs), `maxDriftFromReference`, and `driftTrendSlopePerFrame` (the OLS slope of drift-from-anchor against frame index — the slow-melt signal).
3. **STYLE ADHERENCE** — `style_adherence_distance(frame_style_descriptors, reference_style_descriptor)`. The authorized reference image defines the target style; per output frame a pure-statistics descriptor (per-channel 8-bin L1-normalized color histogram + per-channel means — the SAME extractor on the reference). Reported: `meanStyleDistance` (mean 1−cos), `maxStyleDistance`, `meanChannelShift`.
4. **TEMPORAL CONSISTENCY** — the SHARED estimators IMPORTED from the merged hf010 flight (`ssim_constant_patches` + `flow_warp_residual` — never re-implemented): consecutive-frame SSIM + the flow-warp residual, the same code that scored HF010/HF011, so the Anime/NPR comparison is fair by construction.
5. **COST** — `wall_clock_ms_per_output_second` (the hf010 shared estimator) + cold-start download bytes; GPU peak typed N/A on this host.
